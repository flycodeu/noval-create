# 验收清单

更新时间：2026-05-03  
角色：Agent 1 产出，供 Agent 3 对照执行

## 使用说明

- 验收必须对照 `.agent/repair-plan.md`
- 先验 P0，再验 P1，再看 P2 是否有意外破坏
- 每项按 0 / 1 / 2 分计分
  - 0 = 未满足
  - 1 = 部分满足
  - 2 = 完全满足
- 总分 100 分
- 最终结论要求：
  - P0 不得有未满足项
  - 总分 >= 90
  - 结论为 `PASS`

## 失败时的返工要求

若任一条件满足，则必须判定 `FAIL` 并产出 `.agent/fix-round-1.md`：

- 任一 P0 项未完成
- 总分 < 90
- 主流程链路中存在不可进入、不可保存、整页转圈严重的问题
- TypeScript / lint / build 存在本轮引入的阻塞错误
- 模板系统仍存在明显可见的布局和可读性问题
