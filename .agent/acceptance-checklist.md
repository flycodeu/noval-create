# 验收清单

更新时间：2026-05-03  
角色：Agent 1 产出，供 Agent 3 对照执行  
范围限定：仅验收以下 3 项：

1. `Writing` 拆分
2. 正文内容级断点恢复
3. 非章节生成链路的重试去重一致性

## 使用说明

- 验收必须同时对照：
  - `.agent/repair-plan.md`
  - `docs/todo/41-功能缺陷与改进清单.md`
- 先验 P0，再验 P1
- 每项按 `0 / 1 / 2` 分计分
  - `0 = 未满足`
  - `1 = 部分满足`
  - `2 = 完全满足`
- 总分 100 分
- 通过条件：
  - P0 不得有未满足项
  - 总分 >= 90
  - 结论为 `PASS`
