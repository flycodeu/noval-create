# 人物对白同质化与角色语音指纹扩展

关联总文档：[百万字小说生成问题分析与扩展方案](./百万字小说生成问题分析.md)

## 1. 问题定义

当前系统已要求角色说话有辨识度，但没有对结果进行统计验证。百万字项目一旦对白同质化，角色很快会失去人味，所有人都像同一个模型在说话。

## 2. 当前代码现状

- `electron/services/style-analysis.service.ts` 已支持 `dialogueStyle` 等风格指纹分析。
- `electron/services/context.service.ts` 能将风格指纹注入 prompt。
- `electron/services/story-prompts.ts` 在 rewrite 阶段已要求角色说话体现独特习惯。
- 当前没有“角色之间的对白差异度”分析，也没有角色语音指纹统计。

## 3. 目前已解决 / 部分解决 / 未解决

- 已解决：系统已经意识到对白风格问题。
- 部分解决：有风格指纹和 prompt 要求。
- 未解决：缺少跨角色结果核验。

当前判断：`部分解决`

## 4. 潜在风险

- 多个角色在词汇、语气、句长上没有明显差别。
- 角色在不同卷中的语言习惯会漂移。
- 对白看似流畅，但不具有人物特征。

## 5. 原因分析

- 目前风格约束更偏整章语气，不偏角色级风格。
- 没有把对白按角色切片后做统计分析。
- 缺少主要角色的口头禅、停顿方式、句长偏好等长期记录。

## 6. 扩展方案

- 为主要角色建立语音指纹。
- 统计角色对白的词频、句长、语气词、口头禅、停顿符号、句式偏好。
- 对章节中出现的对白做角色差异度检测。
- 识别“角色之间越来越像”以及“同一角色前后说话风格漂移”的问题。

## 7. 建议的数据结构 / 指标 / 页面能力

- `dialogueFingerprintStats`
- `characterDialogueSignature`
- `crossCharacterDialogueSimilarity`
- `dialogueDriftRate`
- 页面新增“角色对白辨识度”“角色语音漂移趋势”

## 8. 实施优先级

等级：`A级`

等级说明：能显著降低 AI 味并增强人物辨识度，但建立在角色状态更稳之后收益更大。

原因：它对降低 AI 味和提升人物立体感都非常关键。

## 9. 验收标准

- 主要角色具备稳定的对白指纹。
- 系统能识别高相似度对白角色组合。
- 角色对白风格在长篇内可追踪漂移情况。
- 精修后对白同质化程度可量化下降。
