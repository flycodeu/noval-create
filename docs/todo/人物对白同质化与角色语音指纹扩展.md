# 人物对白同质化与角色语音指纹扩展

关联总文档：[百万字小说生成问题分析与扩展方案](./百万字小说生成问题分析.md)

## 1. 问题定义

当前系统已把“角色说话要有辨识度”从 prompt 要求扩成了章节级统计、角色级画像和全书级告警闭环。这个问题的核心实现已经补齐，当前剩余的是复杂对话场景下的说话人归属精度优化。

## 2. 当前代码现状

- `electron/services/dialogue-fingerprint.service.ts` 已建立章节对白切片、角色语音指纹、跨角色相似度和单角色漂移分析链路。
- `electron/database/schema.ts` 与 `electron/database/db.ts` 已新增 `character_dialogue_fingerprints` 表，用于缓存角色级长期画像。
- `electron/services/chapter.service.ts` 会把章节级对白同质化风险、跨角色高相似组合和角色漂移告警写回 `reviewNotesJson`。
- `electron/services/context.service.ts`、`electron/services/context-cards.ts` 已把角色语音画像注入 prompt 上下文。
- `electron/services/quality-dashboard.service.ts` 与 `src/pages/Novel/QualityDashboard/index.tsx` 已展示角色对白辨识度、高相似组合和漂移趋势。
- `src/pages/Novel/Writing/index.tsx` 已在健康卡中展示当前章的对白同质化与语音漂移反馈。

## 3. 目前已解决 / 部分解决 / 未解决

- 已解决：角色语音指纹、跨角色相似度检测、单角色语音漂移追踪、章节级风险回写、质量看板与写作页闭环都已落地。
- 部分解决：说话人归属仍以规则推断为主，复杂多人对话、隐式承接和连续打断场景仍可能出现漏归属或错归属。
- 未解决：暂无新的核心阻塞项，后续重点转向归属精度和更复杂对话场景覆盖。

当前判断：`已解决`

## 4. 潜在风险

- 多个角色在词汇、语气、句长上没有明显差别。
- 角色在不同卷中的语言习惯会漂移。
- 对白看似流畅，但不具有人物特征。

## 5. 原因分析

- 目前风格约束更偏整章语气，不偏角色级风格。
- 没有把对白按角色切片后做统计分析。
- 缺少主要角色的口头禅、停顿方式、句长偏好等长期记录。

## 6. 扩展方案

- 已为主要角色建立语音指纹，并持久化长期画像。
- 已统计角色对白的词频、句长、语气词、口头禅、停顿符号、句式偏好。
- 已对章节中出现的对白做角色差异度检测。
- 已识别“角色之间越来越像”以及“同一角色前后说话风格漂移”的问题。

## 7. 建议的数据结构 / 指标 / 页面能力

- `dialogueFingerprintStats`
- `characterDialogueSignatures`
- `crossCharacterDialogueSimilarity`
- `dialogueDriftTrend`
- 页面已新增“角色对白辨识度”“角色语音漂移趋势”

## 8. 实施优先级

等级：`A级`

等级说明：能显著降低 AI 味并增强人物辨识度，但建立在角色状态更稳之后收益更大。

原因：它对降低 AI 味和提升人物立体感都非常关键。

## 9. 验收标准

- 主要角色已具备稳定的对白指纹。
- 系统已能识别高相似度对白角色组合。
- 角色对白风格在长篇内已可追踪漂移情况。
- 对白同质化已经可量化观测，并回流到章节审校、写作页和质量看板。
