# P2 - 世界观一致性维护不足

> 优先级：P2（中等）
> 影响范围：细节可信度
> 实现难度：中

---

## 问题

百万字小说的世界观细节极其庞大（修炼体系等级、货币兑换比、地理距离、势力关系、历史事件等），AI在长篇生成过程中容易出现：修炼等级名称混乱、距离/时间不合理、已建立的规则被违反、物品能力前后不一致。

## 原因

- 世界规则在上下文中作为P1优先级注入，但token有限时会被截断
- `worldMap` 表记录地理层级但缺少**距离矩阵**和**旅行时间参考**
- `storyItems` 表记录物品但缺少**能力上限**和**使用条件**的结构化字段
- 修炼/力量体系没有专门的结构化表，仅作为文本存储在世界规则中
- `content-guardrails.ts` 的 `world_rules_hollowing` 检测仅针对4个题材，覆盖不全

## 解决方式

1. **结构化世界知识库**：
   - 新建 `world_rules_structured` 表，将世界规则拆分为可查询的键值对
   - 支持类别索引：力量体系、经济体系、社会结构、自然法则等
2. **地理距离矩阵**：在 `mapRelations` 中添加 `distance`、`travelTime`、`travelMethod` 字段
3. **物品能力规格**：扩展 `storyItems` 表，添加 `abilitySpec`、`limitations`、`cooldown` 等结构化字段
4. **世界规则守卫prompt**：每章生成时，注入与该章相关的具体世界规则条目（而非整段世界观描述）
5. **规则违反检测器**：审查阶段增加专门的世界规则一致性检查，对比生成内容与结构化规则库

## 是否解决

已解决 — 2026-04-04

已实施以下修复：
1. 世界规则上下文优先级从 P1 提升到 P0，确保不被 token 预算截断
2. `storyItems` 表新增 `abilitySpec`（能力规格）和 `limitations`（限制）字段
3. `buildItemSummary()` 输出中增加能力、限制和代价信息，上限从 10 条扩展到 12 条
4. 审校prompt增加世界规则一致性检查（角色行为 vs 设定、因果链检查）
5. Token 预算大幅提升确保世界规则不被截断（联动 P0 修复）

## 预期效果

- 修炼等级体系全篇统一
- 地理距离和旅行时间合理
- 物品能力不会随剧情需要任意膨胀
