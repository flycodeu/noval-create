# 成长资源代价系统

## 一、目标

为修仙、奇幻、冒险、末世、生存、权谋等长篇建立“收益循环”，让升级、资源、奖励和代价能够持续驱动篇幅，而不是只靠事件堆积。

## 二、当前已完成

- [x] `story_arcs` 已有 `growthLedger / costLedger`。
- [x] `world_rules`、势力、物品和人物状态里已经出现 `resources / cost / risk / resourceState` 等字段。
- [x] `chapter.service.ts` 已有 `reward_state / cost_present / cost_resolution_state`。
- [x] `quality-dashboard.service.ts` 已监控代价蒸发、奖励缺失、代价持续时间等问题。

## 三、当前未完成

- 无。当前独立页面、资源池、成长轨道与合同绑定链路已经落地。

## 四、模块价值

- 长篇持续推进不只靠剧情，还要靠收益循环。
- 如果资源无限、升级无代价、奖励空心，正文会快速失去张力。

## 五、当前能力结构

- 已有独立页面：`成长资源代价系统`
- 当前核心板块：
  - `成长层级`
  - `稀缺资源`
  - `获取路径`
  - `消耗机制`
  - `失败代价`
  - `阶段奖励节奏`
- 同时支持：
  - `境界 / 等级型`
  - `权力 / 组织型`
  - `关系 / 情感型`

## 六、页面与交互

- 支持从世界规则、物品装备、角色系统、故事设计进入。
- 页面顶部显示“当前主角收益循环健康度”。
- 支持把资源瓶颈直接挂到卷级设计和章节合同。
- 允许从章节回写“本章获得什么 / 失去什么 / 下一阶段卡点是什么”。

## 七、数据结构 / 状态字段

- 当前已落地：
  - `growth_tracks`
  - `resource_pools`
  - `reward_cost_events`
- 当前核心字段：
  - `trackType`
  - `currentTier`
  - `nextGoal`
  - `bottleneck`
  - `scarceResource`
  - `acquirePath`
  - `consumptionRule`
  - `failureCost`
  - `rewardCadence`

## 八、与现有模块的关系

- `世界规则` 定义规则和资源来源。
- `物品装备` 承载资源实例。
- `章节审校 / 质量监控` 继续负责识别奖励空心和代价蒸发。
- `卷级设计` 负责安排阶段性回报与瓶颈升级。

## 九、验收标准

- 能独立查看成长链、资源链和代价链。
- 奖励与代价可被章节回写。
- 质量看板能基于新系统识别成长失速或奖励空心。
- 章节合同可引用“本章必须产生的收益或代价变化”。
