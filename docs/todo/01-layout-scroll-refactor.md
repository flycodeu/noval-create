# 共享布局与滚动模型重构

## 问题
- 非正文页面内容过长时只能整页上下滚动。
- 顶部标题、步骤提示、当前上下文在下翻后容易丢失。
- 左侧筛选、主视图、右侧详情没有形成稳定职责分区。

## 原因
- 后期全局样式把 `novel-route-shell` 和 `novel-workspace` 调回了整体可见滚动。
- `WorkspacePage` 和 `WorkspacePanel` 之前没有提供分区滚动、吸附、步骤指引能力。
- 页面只能各自硬写布局，缺少共享约束。

## 解决措施
- 为共享工作区增加 `scrollMode`，区分 `sectioned` 和 `document`。
- 为共享面板增加 `scrollable` 和 `sticky` 能力，让非正文页面支持分区独立滚动。
- 恢复并统一渲染 hero 眉题、描述、面板描述，减少“只剩标题”的信息缺口。
- 新增共享步骤条组件，统一显示“进入本页先做什么”。

## 状态
- 状态：已解决
- 说明：共享组件和全局样式已补齐，非正文页面可以按分区滚动，正文页保留文档式滚动。
