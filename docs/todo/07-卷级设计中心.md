# 卷级设计中心

## 一、目标

把“全书总主线”与“每卷独立闭环”拆开管理，让长篇既有总目标，也有阶段完成感。

## 二、当前已完成

- [x] 数据层已有 `story_volumes` 与 `story_parts`。
- [x] `结构规划` 已能做卷、部、章编排。
- [x] 质量看板已有卷级指标与卷级风险汇总。
- [x] `workflow.ts` 已把 `volume-planning` 视为关键步骤。
- [x] 已新增独立页面 `src/pages/Novel/VolumeDesign/index.tsx`，并接入 `/novels/:id/volume-design`。
- [x] 已新增 `volume_designs` 表，支持 `volumeTheme / volumePromise / mainConflict / climaxPlan / endStateShift / mustAddClues / mustResolveClues / readerExpectation / auditStatus`。
- [x] 卷级设计页已经可以直接绑定终局承诺，并把“必须新增 / 必须回收的线索”拆成可执行字段。

## 三、当前未完成

- [ ] 没有卷末审计机制。
- [ ] 结构规划和卷级目标之间没有硬约束关系。

## 四、为什么现在要补

- 结构规划只解决“怎么排”，不解决“这一卷为什么值得读完”。
- 百万字要稳，必须是“大主线 + 卷级闭环 + 章末钩子”。

## 五、建议新增内容

- 新增页面：`卷级设计中心`
- 每卷至少维护：
  - `本卷主题`
  - `本卷承诺`
  - `本卷主冲突`
  - `本卷高潮`
  - `卷末状态变化`
  - `本卷必须新增的线索`
  - `本卷必须回收的线索`
  - `卷末读者应产生的期待`

## 六、页面与交互

- 与 `结构规划` 并列，不替代结构规划。
- 左侧按卷导航，右侧显示卷级设计与卷级债务。
- 支持从终局设计导入卷级收束压力。
- 提供“卷后审计”按钮，生成本卷未收线索、人物弧停滞和推进不足清单。

## 七、数据结构 / 状态字段

- 建议在 `story_volumes` 上新增 JSON 扩展，或新增 `volume_designs` 表。
- v1 最少字段：
  - `volumeTheme`
  - `volumePromise`
  - `mainConflict`
  - `climaxPlan`
  - `endStateShift`
  - `mustAddClues`
  - `mustResolveClues`
  - `readerExpectation`
  - `auditStatus`

## 八、与现有模块的关系

- `故事设计` 管全书总设计。
- `卷级设计中心` 管每卷闭环。
- `结构规划` 管排布。
- `质量监控` 与 `章节验收门` 在卷末读取卷级目标做审计。

## 九、验收标准

- 每卷都能独立维护主题、承诺、冲突和高潮。
- 卷级目标可被结构规划和章节合同引用。
- 卷后审计可以输出未回收线索、失速弧线和推进不足章节。
- 质量看板能按卷显示“承诺兑现率”。
