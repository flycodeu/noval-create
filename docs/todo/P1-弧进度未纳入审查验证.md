# P1 - 弧进度未纳入审查验证

> 优先级：P1（严重）
> 影响范围：长弧静默偏离目标
> 实现难度：中
> 类别：后端-质量控制

---

## 问题

连续性状态中定义了 `arcProgress` 字段，但审查prompt并未要求AI验证弧目标是否正在被推进。对于100章的长弧，第30-50章可能完全偏离弧目标而不被检测，直到第70章才发现，此时需要大量返工。

## 原因

- `story-prompts.ts` 的review prompt检查了线索和伏笔，但未检查弧级别的目标推进
- `continuityState` 虽有 `arcProgress` 字段，但未在审查环节被使用
- 缺少"弧目标完成度"的量化追踪
- 长弧中间章节容易失去方向感

## 解决方式

1. **审查prompt增加弧目标验证**：检查当前章节是否在推进弧目标，偏差时标记警告
2. **弧进度百分比追踪**：在 `storyArcs` 表添加 `progressPercent` 字段，每章更新
3. **弧偏离预警**：连续5章未推进弧目标时自动告警
4. **弧中间检查点**：在弧的25%/50%/75%位置自动检查目标对齐度

## 是否解决

已解决

## 预期效果

- 每个弧始终朝目标推进
- 偏离时及早发现并修正
- 100章长弧也能保持叙事聚焦
