# P0 - 导出文件名路径穿越风险

> 优先级：P0（致命）
> 影响范围：文件系统安全
> 实现难度：低
> 类别：后端-导出服务

---

## 问题

`sanitizeFileName()` 函数只替换 `<>:"/\|?*` 和控制字符，但未验证最终路径是否仍在预期的导出目录内。虽然 `\` 和 `/` 会被替换为 `_`，但存在以下风险：

1. Unicode 目录分隔符等边界情况可能绕过过滤
2. `createExportDirectory()` 的 `baseDir` 参数来自用户选择的对话框，未做路径验证
3. `path.join()` 不会阻止路径逃逸

```typescript
function sanitizeFileName(value: string, fallback: string): string {
  const normalized = (value || '').trim().replace(/[<>:"/\\|?*\u0000-\u001f]+/g, '_')
  const collapsed = normalized.replace(/\s+/g, ' ').trim()
  return collapsed || fallback
}
```

## 原因

- `electron/services/export.service.ts:31-34` sanitizeFileName 缺少路径穿越防护
- `electron/services/export.service.ts:426-435` createExportDirectory 未用 `path.resolve()` 验证最终路径前缀

## 解决方式

1. 在 `sanitizeFileName()` 中额外过滤 `..` 序列
2. 在 `createExportDirectory()` 中使用 `path.resolve()` 获取绝对路径后，验证其是否以 `baseDir` 为前缀
3. 如果最终路径逃逸了 `baseDir`，抛出错误中止导出
