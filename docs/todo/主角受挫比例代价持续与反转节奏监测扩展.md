# 主角受挫比例代价持续与反转节奏监测扩展

关联总文档：[百万字小说生成问题分析与扩展方案](./百万字小说生成问题分析.md)

## 1. 问题定义

小说不能长期让主角一路顺推。当前系统虽然能识别“零代价解决”这类单点问题，但还不能从长期视角判断主角是否真正受挫、代价是否持续、反转是否合理分布。

## 2. 当前代码现状

- `src/shared/content-guardrails.ts` 已能识别 `zero_cost_resolution`。
- `electron/services/story-prompts.ts` 已要求章节有推进、阻力和代价。
- `electron/services/chapter.service.ts` 审校中已包含 `reader_hook_risks`、`realism_risks` 等字段。
- 当前没有长期统计“主角多久受挫一次、代价持续多久、反转出现在什么位置”。

## 3. 目前已解决 / 部分解决 / 未解决

- 已解决：章节审校已结构化输出主角受挫、代价状态、反转支撑、节奏标签、阶段回报和主角压力。
- 已解决：质量看板已新增主角受挫曲线、代价持续摘要、反转/高潮/喘息分布、卷级结构摘要与节奏告警。
- 已解决：写作页健康面板与发布前检查已接入主角与节奏风险，能提示顺推、代价蒸发、强行反转和高潮间隔异常。

当前判断：`已解决`

## 4. 潜在风险

- 主角看上去总在赢，读者感受不到真正风险。
- 大伤大损失过一章就恢复，代价失真。
- 反转不是铺垫后的兑现，而是为了刺激而硬塞。

## 5. 原因分析

- 当前检测集中在单章合理性，不是长期结构合理性。
- 缺少主角受挫、恢复、反败为胜的分布统计。
- 缺少“反转是否由前文铺垫支撑”的量化追踪。

## 6. 扩展方案

- 新增主角受挫率、恢复成本、代价持续章节数统计。
- 新增反转标记、高潮标记和喘息标记，做分布图。
- 将主角重大失败、重大损失、关键反转接入卷级看板。
- 对“无代价爽点”与“长期压抑无回报”都做平衡检测。

## 7. 建议的数据结构 / 指标 / 页面能力

- `costLedger`
- `protagonistSetbackRate`
- `costDuration`
- `reversalMarkers`
- `climaxSpacing`
- 页面新增“主角受挫与恢复曲线”“反转分布图”

## 8. 实施优先级

等级：`S级`

等级说明：直接决定小说感、追读感，以及主角不能总是一帆风顺的控制能力。

原因：这是最直接影响读者追读欲和小说感的维度之一。

## 9. 验收标准

- 系统能统计主角受挫和恢复的长期分布。
- 关键反转和高潮可按章节可视化。
- 代价不会在没有解释的情况下快速蒸发。
- 长篇中“主角长期一帆风顺”的风险可被提前告警。
