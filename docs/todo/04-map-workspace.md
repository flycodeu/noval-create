# 地图工作区重构

## 问题
- 地图页图谱、列表、详情在信息多时仍然容易互相挤压。
- 详情检查器和列表详情栏虽然有分区，但滚动和吸附不够统一。
- 自动生成任务卡、关系编辑、节点详情容易抢占主视图注意力。

## 原因
- 列表模式和图谱模式各自维护布局，缺少统一滚动约束。
- 局部已经有 sticky，但吸附偏移和共享布局没有统一。
- AI 和详情操作都堆在主工作区附近，视觉主次不够稳定。

## 解决措施
- 图谱模式继续保持主画布优先，右侧检查器统一为焦点、关系、详情三种职责。
- 列表模式三栏全部支持独立滚动，详情栏保持吸附。
- 统一 AI 文案为“AI 生成·层级骨架”和“AI 补全·当前节点”。
- 吸附偏移改为共享变量，避免和全局 sticky header 冲突。

## 状态
- 状态：已解决
- 说明：图谱检查器、列表栏和详情栏的独立滚动已接入，共享吸附偏移已统一。
