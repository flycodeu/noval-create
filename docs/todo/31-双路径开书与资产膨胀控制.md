# 双路径开书与资产膨胀控制

## 一、目标

支持两条清晰开书路径：

- 专业长篇路径：保留现有重底盘、重结构、重一致性的完整流程。
- 极速开书路径：仅输入最小必要信息，快速生成可写的前几章骨架并进入正文。

同时建立资产膨胀控制机制，避免用户不断补资产却长期无法落到正文。

## 二、为什么现在要做

当前系统更适合愿意完整搭底盘的作者，但不适合所有作者。对一部分用户来说，前期资产搭建成本过高，会直接影响转化和留存。

## 三、当前已覆盖基础

- 新建小说向导已经支持题材、背景、AI 补全和基础项目创建。
- 现有底盘模块已经能承接专业长篇路径所需的大部分信息。
- 结构规划、章节合同、正文写作和章后回写已经形成可继续扩展的正文主链路。

## 四、待办拆分

- [x] 在新建入口提供“专业长篇路径 / 极速开书路径”双路径选择。
- [x] 已定义极速开书的 6 个必填字段：题材、主角起点、核心钩子、核心冲突、禁区、终局方向。
- [x] 已基于 6 字段自动生成基础立项、文风护栏、第一卷目标、前三章骨架、主线线程和主角/反派简版卡。
- [x] 已允许用户在进入正文后边写边长资产，而不是先要求补完整个资产库。
- [x] 已新增首期资产膨胀指标：资产总量、首章前结构承接覆盖与风险等级，并把更细的引用率/使用率口径留给后续阶段。
- [x] 当资产增长快于正文推进时，创作总览、创作向导与侧栏都会提示“优先进入正文 / 先压成大纲”。

## 五、详细设计

### 5.1 专业长篇路径

沿用当前主链路：

基础信息 -> 项目立项 -> 基础设定 -> 主题与文风 -> 世界规则 -> 终局设计 -> 资产建设 -> 故事设计 -> 结构规划 -> 合同 -> 正文

### 5.2 极速开书路径

只要求用户先完成：

- 题材
- 主角起点
- 核心钩子
- 核心冲突
- 禁区
- 终局方向

然后自动补出：

- 基础立项
- 文风护栏
- 第一卷目标
- 前三章骨架
- 主角 / 反派简版卡
- 最小世界规则集

### 5.3 资产膨胀控制

创作总览与质量系统都要识别“资产越来越多，但正文迟迟不开始”的情况，并优先把建议动作切回首章或下一章。

## 六、验收标准

- 用户可以在不补全所有资产的情况下进入第一章写作。
- 两种路径共享后续长篇控制能力，不会分裂成两套系统。
- 系统能识别资产膨胀并给出纠偏提示。
- 极速路径生成的基础资产足以支撑第一卷和前三章。

## 七、风险与建议

- 极速路径不能因为快而牺牲最基本的约束和禁区。
- 自动补齐出来的资产必须保持可编辑，不要锁死。
- 双路径最终仍要回到同一套结构化创作知识库，避免长期分叉。
