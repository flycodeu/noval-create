# 40 - 组件样式迁移与暗色主题适配

## 一、问题概述

当前系统存在严重的**样式分裂**：

1. **全局 CSS 文件** (`global.css`) 定义了三套主题变量（light/dark/soft）
2. **页面级 CSS 文件** (Studio/index.css 等) 只适配了亮色主题
3. **核心组件** (ProjectSidebar/ProjectTopbar/NovelList) 全部使用内联样式，完全绕过主题系统
4. **结果**：切换到 dark/soft 主题时，大量区域仍显示白色背景 + 深色文字

## 四、消除 `!important` 的策略

**当前问题**：global.css 中有大量 `!important` 用于覆盖 Ant Design 默认样式。

**改进方案**：

1. 使用**更高特异性选择器**替代 `!important`：
   ```css
   /* 旧 */
   .ant-menu-item { color: #fff !important; }
   
   /* 新 */
   .app-layout .ant-menu-item { color: var(--text-primary); }
   ```

2. 优先使用 **Ant Design ConfigProvider token** 替代 CSS 覆盖：
   ```tsx
   <ConfigProvider theme={{
     components: {
       Menu: { itemColor: 'var(--text-primary)' }
     }
   }}>
   ```

3. 对于必须使用 CSS 覆盖的场景，使用 `:where()` 降低 Ant Design 选择器特异性（Ant Design 5.x 已支持）
