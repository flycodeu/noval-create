# 长篇系统扩展总览

## 一、目标

把当前系统从“已经具备长篇底盘的 AI 小说工作台”，扩成“可以稳定推进百万字长篇”的结构化创作系统。重点不是新增更多页面，而是补齐长篇真正依赖的收束、弧线、合同、回写和门禁。

## 二、当前代码已覆盖能力摘要

- 已有全书级底盘：基础信息、项目立项、基础设定、主题与文风、世界规则。
- 已有第一版 `终局设计`：独立页面、`endgame_design` 字段、工作流就绪度、上下文与时间轴摘要接入。
- 已有中观结构：故事设计、故事大纲、结构规划、时间轴、故事线程。
- 已有章节生产流水线：`planning -> drafting -> reviewing -> rewriting`。
- 已有章节发布检查：写作页在标记完成前会执行 `runChapterPublishCheck`。
- 已完成四级 `章节验收门`：覆盖 `通过 / 预警 / 阻塞 / 退回重写`，并补齐 POV、钩子、线程推进、卷目标一致性和修订任务联动。
- 已完成 `章节场景合同执行器`：正文会校验章节目标、场景冲突/结果、线程推进、伏笔处理和章尾钩子，并把失败项转成重写提示。
- 已完成 `反AI味前置抑制器`：反 AI 味规则会在生成前进入硬约束，命中会写入 `anti_ai_rule_hits`，连续复现会自动升级到下一章并进入质量看板。
- 已完成 `审校反哺与复现率闭环`：审校、章节门、合同校验和 anti-AI 命中会归一化为通用复现问题，自动前置到下一章并在高风险时暂停批次。
- 已补 `workspace-quality` 人类化信号回流：解释腔、模板衔接、空转修辞、锚点不足、立场发虚等问题已能写回章节审校、进入下一章硬约束，并在质量面板中独立聚合。
- 已完成 `风格指纹硬约束化`：风格指纹已拆成软参考与硬约束，生成后会产出合规分，并进入章节门和质量看板。
- 已有伏笔相关基础：`story_threads` 包含 `plantedChapter / targetPayoffChapter / resolvedChapter`，并提供 `getForeshadowSnapshot`。
- 已有状态回写基础：章节后会刷新 `characterStateVersions`、`worldStateVersions`、时间线锚点、故事记忆和部分实体发现。
- 已有质量基础：对白指纹、语言漂移、代价蒸发、召回风险、状态风险、故事弧推进预警。
- 已有上下文分层基础：硬约束、软上下文、故事核心、当前弧线、人物状态、世界状态、伏笔压力、时间轴、长期记忆。

## 三、当前关键缺口

- `02-人物弧线中心` 的页面与基础联动已落地，但“自动判断本章是否真的推进弧线并自动回写”的闭环仍未完全收口。
- `29-任务中心化工作台与四模式入口`、`30-创作总览行动化与零状态引导` 已基本完成，但 Dashboard 的信息层级、参考层折叠和少量动作化提示仍会继续细化。
- `32-资产变更影响分析与写作闭环自动化`、`33-质量监控升级为修复引擎`、`34-AI引擎强化与可解释生成` 的主链路已可用，但仍属于“高完成度、持续强化”的系统能力，不再按“纯缺失”看待。
- `38-布局样式全面改造方案` 已完成本轮主要 UI 止血与主题一致性修复，但全站 token 收口、历史页样式清理仍有后续空间。
- `41-功能缺陷与改进清单` 中仍保留少量真实未完成功能，例如 `Writing` 大文件拆分、网络中断后的正文内容级断点恢复、部分 Dashboard 层级优化。

## 四、优先级

| 优先级 | 模块 |
| --- | --- |
| P0 | 继续细化 AI 引擎统一层、资产影响审计与自动闭环验证 |
| P1 | 继续优化工作台层级、创作总览行动反馈、开书向导体验 |
| P2 | 持续推进质量修复引擎、纵向趋势分析与门禁漂移监控 |

## 五、建议实施顺序

1. 继续细化已完成模块的自动验收、联动回写与审计能力。
2. 先补 `34-AI引擎强化与可解释生成`，把上下文组装器、结构化输出、模型路由、多轮审校链、作者风格锁和生成可解释性收拢成统一主线。
3. 再补 `32-资产变更影响分析与写作闭环自动化`，把资产变更、注入、回写、校验和修订中心串成自动闭环。
4. 再补 `29-任务中心化工作台与四模式入口`、`30-创作总览行动化与零状态引导`、`31-双路径开书与资产膨胀控制`，把已有能力组织成更低认知负担的作者工作流。
5. 最后补 `33-质量监控升级为修复引擎` 与更细的趋势分析，完成从“发现问题”到“直接修复”的闭环。

## 八、推荐长篇流程
