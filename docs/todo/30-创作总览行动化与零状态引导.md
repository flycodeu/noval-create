# 创作总览行动化与零状态引导

## 一、目标

把 `创作总览` 从展示页升级为行动页。它不只是展示完成度、章节数和资产数，而是明确告诉作者“现在最该做什么、为什么是它、做完会解锁什么”。

## 二、为什么现在要做

当前总览页已经有推荐下一步、风险和健康摘要，但视觉重心仍偏分散，零状态项目尤其容易出现“信息有了，起步动作不够强”的问题。

## 三、当前已覆盖基础

- 当前总览页已经能展示推荐下一步、风险、字数、章节数和修订任务数。
- `27-质量仪表盘与百万字健康指标` 已把百万字健康总灯接入总览。
- 工作流与修订系统已经能提供阻塞信息和是否建议继续的判断。
- `29-任务中心化工作台与四模式入口` 已把共享主任务摘要接入 `创作总览`，并与 `创作向导` 复用同一套模式判定逻辑。

## 四、边界说明

- `29` 负责“模式判定、主任务、备选任务、阻塞和影响”的共享工作流层。
- `30` 负责把 `创作总览` 自身重做成更强的行动页与零状态页。
- 因此本项不会再重复实现一套模式推荐器，而是在总览的布局、信息优先级、零状态和操作分层上继续深化。

## 五、待办拆分

- [x] 总览已接入共享主任务摘要，不再只显示统计和静态推荐。
- [x] 顶部信息区已改为“主任务 + 备选路径/首章启动路径 + 阻塞项 + 风险影响”四块核心区。
- [x] 零状态项目不再优先展示章节统计、推进热度等弱信息，已改为首章启动动作。
- [x] 顶部按钮层级已收紧为单主按钮，基础信息编辑动作已下沉到面板内部。
- [x] 修订任务已做阶段化降噪，`0 章 / 0 字` 阶段不再默认展示修订和健康噪音。

## 六、详细设计

### 5.1 四个核心区

保留总览全局感，但主视觉只保留以下三类核心信息：

- 今天最该做什么
- 备选路径 / 首章启动路径
- 当前阻塞项
- 风险和影响

当前已落地为 4 块核心区，而不是继续把推荐、统计、表单混在同一层。

### 5.2 零状态引导

新项目处于 `0 章 / 0 字` 时，优先展示：

- 创建第一卷
- 生成前三章骨架
- 创建主角与反派
- 生成第一章场景合同
- 开始第一章草稿

### 5.3 操作分层

顶部操作建议口径：

- 主按钮：推荐下一步
- 搜索入口：全局搜索 / 命令面板
- 更多菜单：快捷键、跳转、撤销、清空当前步骤等

当前版本已先落地主按钮收敛；搜索入口和更多菜单暂不在本项内新增。

## 七、验收标准

- 新用户首次进入总览时，不需要先理解所有模块也能开始推进。
- 零状态项目下，动作入口明显强于统计信息。
- 顶部操作存在主次层级，不会出现十几个平权按钮。
- 总览能解释“为什么推荐这一步”，而不是只给跳转链接。

## 八、风险与建议

- 不能把所有摘要都塞回总览，否则行动化会再次退化成展示化。
- 阶段化降噪必须和修订、质量的真实阈值联动，不能只靠前端隐藏。
- 有效性 badge 的判定口径要稳定，否则用户会觉得数值飘忽。
