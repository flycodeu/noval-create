# 质量看板章节化与卷级全书级诊断扩展

关联总文档：[百万字小说生成问题分析与扩展方案](./百万字小说生成问题分析.md)

## 1. 问题定义

当前质量看板已经能看章节评分和 AI 味趋势，但它仍然是章节化的展示系统。对于百万字小说，真正需要的是卷级和全书级的诊断面板，用来发现长期结构问题。

## 2. 当前代码现状

- `electron/services/quality-dashboard.service.ts` 基于 `aiScoreJson` 构建热力图、总分趋势、AI 味率趋势、薄弱维度频次。
- `src/pages/Novel/QualityDashboard/index.tsx` 主要展示章节维度数据。
- 当前没有卷级聚合指标，也没有全书级结构诊断入口。
- 写作页能展示局部风险，但不能替代全局健康中台。

## 3. 目前已解决 / 部分解决 / 未解决

- 已解决：已有章节级评分展示。
- 部分解决：已能看章节趋势，但粒度仍偏细。
- 未解决：没有卷级、全书级诊断。

当前判断：`部分解决`

## 4. 潜在风险

- 某一卷已经开始语言退化，但章节分散看不明显。
- 某条人物弧或故事弧长期停滞，但看板无法聚合显示。
- 项目规模越大，章节级数据越难支持决策。

## 5. 原因分析

- 当前看板数据源仍主要围绕单章 `aiScoreJson`。
- 没有卷级和全书级指标模型。
- 缺少跨章节聚合的结构性指标，如空转率、反转密度、伏笔债务。

## 6. 扩展方案

- 保留现有章节级看板。
- 新增卷级指标层，聚合节奏、人物弧、故事弧、AI 味、伏笔、代价数据。
- 新增全书级健康层，展示全书长期趋势和关键风险。
- 将章节级问题上卷到卷级，将卷级问题再上卷到全书级。

## 7. 建议的数据结构 / 指标 / 页面能力

- `volumeQualityMetrics`
- `novelQualityMetrics`
- `volumeArcProgress`
- `volumeAiTrend`
- `novelRiskOverview`
- 页面新增“卷级健康面板”“全书健康总览”

## 8. 实施优先级

等级：`S级`

等级说明：没有上层看板，前面的治理能力难以形成可操作的闭环。

原因：如果没有更高层的看板，前面所有检测能力很难真正帮助决策。

## 9. 验收标准

- 质量看板同时支持章节级、卷级、全书级视图。
- 卷级可显示弧推进、伏笔债务、AI 味、节奏、人物弧数据。
- 全书级可显示长期趋势和关键风险概览。
- 用户能从全书级逐层钻取到卷级、章节级问题。
