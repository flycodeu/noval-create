# P1 - 叙事节奏单调

> 优先级：P1（严重）
> 影响范围：阅读体验
> 实现难度：中

---

## 问题

AI生成的长篇小说容易陷入"匀速叙事"——每章字数相近、情绪强度相近、信息密度相近。缺少人类作家的节奏控制能力：紧张时短句密集、舒缓时长句铺陈、高潮前的蓄力留白。百万字小说尤其需要宏观节奏把控（卷级起伏）和微观节奏变化（段落级松紧）。

## 原因

- `chapters` 表的 `targetWords` 默认3000字，所有章节一刀切
- `emotionTone` 字段仅记录单一情绪标签，缺少节奏曲线建模
- 弧（arc）级别虽有 `arcGoal`，但没有节奏模板（起承转合的具体分配）
- prompt中缺少对叙事节奏的具体量化指导（如"本章前半段节奏紧凑，每段不超过3句"）
- 缺少**节奏参照系**：没有对前几章的节奏进行分析，导致连续多章节奏雷同

## 解决方式

1. **宏观节奏曲线**：
   - 为每个卷/弧定义情绪曲线模板（如：铺垫→小高潮→低谷→蓄力→大高潮→余韵）
   - 将曲线映射到具体章节的字数、情绪强度、信息密度参数
2. **微观节奏控制**：
   - 在 `buildChapterDraftPrompt()` 中注入句式节奏指令
   - 紧张场景：短句为主，段落<100字，对话密集
   - 舒缓场景：长句铺陈，环境描写丰富，段落200-300字
3. **节奏反馈循环**：
   - 审查阶段分析上一章的节奏特征（平均句长、对话比、描写比）
   - 如果连续3章节奏相似，自动调整下一章的节奏参数
4. **字数动态分配**：
   - 高潮章节：4000-5000字（充分展开）
   - 过渡章节：2000-2500字（快速推进）
   - 悬念章节：2500-3000字（适度留白）

## 是否解决

已解决 — 2026-04-04

已实施以下修复：
1. 新增 `buildRhythmGuide()` 函数，根据 `emotionTone` 自动生成节奏指导：
   - 高潮节奏：短句（≤15字）、紧凑段落（≤100字）、对话密集、字数可上浮20%
   - 过渡节奏：长短句交替、舒展段落、字数可下调20%
   - 悬念节奏：句子长短参差、关键信息放段尾、留白和省略
   - 沉郁节奏：偏长句、重感官细节、对话少而重
2. `buildChapterDraftPrompt()` 和 `buildChapterWritingPrompt()` 均注入节奏指导
3. 节奏指导包含具体的句子长度、段落长度、对话密度等量化参数

## 预期效果

- 读者能感受到明显的起伏节奏
- 高潮前有蓄力，高潮后有余韵
- 不再是"每章3000字的流水账"
