# P2 - Anthropic适配器无重试机制

> 优先级：P2（中等）
> 影响范围：网络波动时章节生成失败率高
> 实现难度：低
> 类别：后端-适配器

---

## 问题

OpenAI适配器有重试逻辑（line 89-127），但Anthropic适配器**完全没有重试机制**。网络中断时：
- 章节半写入（3000字目标可能只写了1500字）
- 错误抛出，任务标记失败
- 部分内容未保存

## 原因

- `electron/adapters/anthropic.adapter.ts:36-73` 缺少错误重试逻辑
- 未检测瞬态错误（ECONNRESET、ETIMEDOUT等）
- 无部分内容保存机制
- 各适配器的容错能力不一致

## 解决方式

1. **统一适配器重试接口**：抽取公共的重试逻辑，所有适配器复用
2. **瞬态错误检测**：识别网络错误并自动重试（最多3次，指数退避）
3. **部分内容保存**：流式生成中断时保存已接收内容，支持断点续写
4. **适配器健康检查**：启动时验证各适配器连通性

## 是否解决

已解决

## 预期效果

- 网络短暂波动不再导致整章丢失
- 各AI适配器容错能力一致
- 部分生成内容可恢复
