# P1 - 对话质量与角色辨识度不足

> 优先级：P1（严重）
> 影响范围：角色表现力
> 实现难度：中

---

## 问题

AI生成的对话普遍存在"所有人说话像一个人"的问题：缺少方言/口语特色、情绪表达方式雷同、对话过于书面化、缺少打断/省略/口误等自然语言特征。百万字小说中角色众多，对话辨识度直接影响阅读体验。

## 原因

- `characters` 表虽有40+字段描述角色，但缺少**语言画像**专属字段（说话方式、口头禅、用词偏好）
- 对话生成时，角色语言特征未被显式注入prompt
- 缺少对话风格的few-shot示例
- 审查阶段（`buildChapterReviewPrompt`）未包含对话辨识度检查
- 缺少**对话节奏**控制：现实对话中的停顿、打断、话题跳转等特征被忽略

## 解决方式

1. **角色语言画像系统**：
   - 在 `characters` 表添加 `speechPattern`（说话模式）、`catchphrases`（口头禅）、`vocabularyLevel`（用词水平）、`dialectFeatures`（方言特征）字段
   - 生成角色时自动生成语言画像
2. **对话生成专用prompt**：
   - 在对话密集的场景中，注入各参与角色的语言画像
   - 提供该角色的3-5句历史对话作为风格参考
3. **对话审查规则**：
   - 检测连续两个角色的对话是否过于相似（词频分析）
   - 检测对话是否过于书面化（文言/成语密度过高）
4. **自然语言特征注入**：
   - 根据场景紧张度，添加打断、省略、重复等自然对话特征
   - 情绪激动时句子变短，思考时出现停顿

## 是否解决

已解决 — 2026-04-04

已实施以下修复：
1. `characters` 表新增 `speechPattern`（说话方式）、`catchphrases`（口头禅）、`vocabularyLevel`（用词水平）、`dialectFeatures`（方言特征）四个语言画像字段
2. `buildCharacterStates()` 自动将语言画像注入角色上下文，供写作时参考
3. `GLOBAL_WRITING_RULES` 新增第10-11条：对话辨识度要求和对话真实感要求
4. `buildChapterRewritePrompt()` 增加对话辨识度和自然度的专项指令
5. 对话自然度指令覆盖：打断、省略、口误、沉默、答非所问、上下级/亲疏温度差异

## 预期效果

- 遮住角色名也能通过说话方式辨别角色
- 对话更接近口语，减少书面感
- 情绪状态通过说话方式自然体现
