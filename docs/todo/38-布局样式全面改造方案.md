# 38 - 布局样式全面改造方案

## 一、当前样式问题总览

### 1.1 核心问题

| 问题类型 | 严重程度 | 影响范围 |
|----------|----------|----------|
| 内联样式泛滥 | 高 | ProjectSidebar、ProjectTopbar、NovelList 等全部组件 |
| 颜色体系混乱 | 高 | 20+ 不同色值散布在 CSS 和内联中 |
| 间距不统一 | 中 | 12/14/18/20/22px 无规律混用 |
| 暗色主题不完整 | 高 | 页面级 CSS 全部只有亮色适配 |
| 字体层级模糊 | 中 | 11-32px 无清晰层级体系 |
| 圆角不统一 | 低 | 6/8/12/16/18/20/22/24/32px 混用 |
| 侧边栏宽度不一致 | 中 | 236/280/300/320px 不同页面不同值 |

### 1.2 内联样式问题

**ProjectSidebar.tsx**（206 行）：全部用 `style={{...}}` 实现，零 CSS 类。导致：
- 暗色/Soft 主题无法覆盖（内联优先级最高）
- 无法复用，维护困难
- 渲染性能差（每次 re-render 创建新对象）

**ProjectTopbar.tsx**：同样全部内联。

**NovelList/index.tsx**：header、stats cards、search bar、project grid 全部内联。

## 二、颜色体系改造

### 2.1 当前问题

CSS 变量体系存在**两套并行**的命名：

```css
/* 旧体系 */
--bg-page, --bg-panel, --bg-soft
--text-main, --text-sub, --text-muted
--border-light, --border-strong
--primary, --primary-hover, --primary-soft

/* 新体系 */
--color-bg-primary, --color-bg-secondary, --color-bg-card
--color-text-primary, --color-text-secondary, --color-text-muted
--color-blue-primary, --color-blue-dark
```

两套变量值不一致，页面级 CSS 使用旧体系，组件内联使用新旧混用。

### 2.2 改造方案

**统一为一套语义化变量**：

```css
:root {
  /* === 背景层级 === */
  --bg-app:      #F5F6F8;    /* 最底层页面背景 */
  --bg-surface:  #FFFFFF;    /* 卡片/面板表面 */
  --bg-elevated: #FFFFFF;    /* 弹窗/浮层 */
  --bg-muted:    #FAF7F1;    /* 柔和区块背景 */
  --bg-hover:    #EEF2F6;    /* 悬停态 */
  --bg-active:   #F3E7D8;    /* 选中/激活态 */

  /* === 文字层级 === */
  --text-primary:   #1F2937; /* 标题、正文主色 */
  --text-secondary: #6B7280; /* 副标题、说明文字 */
  --text-muted:     #9CA3AF; /* 辅助文字、占位符 */

  /* === 边框 === */
  --border-default: #E5E7EB;
  --border-strong:  #D1D5DB;

  /* === 主题色 === */
  --accent:       #A66A2B;   /* 主操作色 */
  --accent-hover: #8F5720;
  --accent-soft:  #F3E7D8;   /* 低饱和度背景 */

  /* === 语义色 === */
  --success: #2F855A;
  --warning: #B7791F;
  --danger:  #C2410C;
  --info:    #2563EB;

  /* === 圆角（只保留 4 级）=== */
  --radius-s:  6px;
  --radius-m:  10px;
  --radius-l:  14px;
  --radius-xl: 20px;

  /* === 间距（只用 4px 的倍数）=== */
  --space-xs:  4px;
  --space-s:   8px;
  --space-m:   12px;
  --space-l:   16px;
  --space-xl:  24px;
  --space-2xl: 32px;

  /* === 阴影 === */
  --shadow-sm:  0 1px 3px rgba(0,0,0,0.06);
  --shadow-md:  0 4px 12px rgba(0,0,0,0.08);
  --shadow-lg:  0 12px 24px rgba(0,0,0,0.1);
  --shadow-xl:  0 20px 40px rgba(0,0,0,0.12);
}
```

- 筛选控件使用 `flex-wrap: wrap` 确保窄屏不溢出

## 四、全局样式修复清单

### 4.1 暗色主题适配

**需要修改的文件**：

| CSS 文件 | 需要适配的内容 |
|----------|---------------|
| `Studio/index.css` | `--studio-ink`、`--studio-panel` 需要暗色变体 |
| `Writing/index.css` | 段落背景、分数卡片颜色 |
| `Characters/character-workspace.css` | 节点样式、图背景 |
| `Structure/index.css` | 拖拽手柄、卡片背景 |
| `Factions/index.css` | 图节点、面板背景 |
| `MapExplorer/map-explorer.css` | inspector 面板 |
| 所有组件内联样式 | `#fff` → `var(--bg-surface)` |

**通用方案**：在每个页面 CSS 末尾添加 `[data-theme="dark"]` 覆盖块。

### 4.2 间距规范化

统一使用 4px 倍数体系：

| 场景 | 当前值（混用） | 规范值 |
|------|--------------|--------|
| 组件内部间距 | 6/8/10px | 8px (`--space-s`) |
| 元素间距 | 12/14px | 12px (`--space-m`) |
| 模块间距 | 16/18px | 16px (`--space-l`) |
| 区域间距 | 20/22/24px | 24px (`--space-xl`) |
| 大段落间距 | 28/30/32px | 32px (`--space-2xl`) |

### 4.3 字体层级规范化

| 层级 | 用途 | 大小 | 字重 | 行高 |
|------|------|------|------|------|
| H1 | 页面标题 | 24px | 700 | 1.3 |
| H2 | 区块标题 | 18px | 700 | 1.4 |
| H3 | 卡片标题 | 15px | 600 | 1.4 |
| Body | 正文 | 14px | 400 | 1.6 |
| Caption | 辅助说明 | 12px | 400 | 1.5 |
| Overline | 分类标签 | 11px | 700 | 1.2 |

### 4.4 圆角规范化

| 层级 | 当前值（混用） | 规范值 | 用途 |
|------|--------------|--------|------|
| S | 6/8px | 6px | 按钮、输入框、小标签 |
| M | 10/12px | 10px | 卡片、面板 |
| L | 14/16/18px | 14px | 大面板、模态框 |
