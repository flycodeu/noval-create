## 二、颜色体系改造

### 2.1 当前问题

CSS 变量体系存在**两套并行**的命名：

```css
/* 旧体系 */
--bg-page, --bg-panel, --bg-soft
--text-main, --text-sub, --text-muted
--border-light, --border-strong
--primary, --primary-hover, --primary-soft

/* 新体系 */
--color-bg-primary, --color-bg-secondary, --color-bg-card
--color-text-primary, --color-text-secondary, --color-text-muted
--color-blue-primary, --color-blue-dark
```

两套变量值不一致，页面级 CSS 使用旧体系，组件内联使用新旧混用。

### 2.2 改造方案

**统一为一套语义化变量**：

```css
:root {
  /* === 背景层级 === */
  --bg-app:      #F5F6F8;    /* 最底层页面背景 */
  --bg-surface:  #FFFFFF;    /* 卡片/面板表面 */
  --bg-elevated: #FFFFFF;    /* 弹窗/浮层 */
  --bg-muted:    #FAF7F1;    /* 柔和区块背景 */
  --bg-hover:    #EEF2F6;    /* 悬停态 */
  --bg-active:   #F3E7D8;    /* 选中/激活态 */

  /* === 文字层级 === */
  --text-primary:   #1F2937; /* 标题、正文主色 */
  --text-secondary: #6B7280; /* 副标题、说明文字 */
  --text-muted:     #9CA3AF; /* 辅助文字、占位符 */

  /* === 边框 === */
  --border-default: #E5E7EB;
  --border-strong:  #D1D5DB;

  /* === 主题色 === */
  --accent:       #A66A2B;   /* 主操作色 */
  --accent-hover: #8F5720;
  --accent-soft:  #F3E7D8;   /* 低饱和度背景 */

  /* === 语义色 === */
  --success: #2F855A;
  --warning: #B7791F;
  --danger:  #C2410C;
  --info:    #2563EB;

  /* === 圆角（只保留 4 级）=== */
  --radius-s:  6px;
  --radius-m:  10px;
  --radius-l:  14px;
  --radius-xl: 20px;

  /* === 间距（只用 4px 的倍数）=== */
  --space-xs:  4px;
  --space-s:   8px;
  --space-m:   12px;
  --space-l:   16px;
  --space-xl:  24px;
  --space-2xl: 32px;

  /* === 阴影 === */
  --shadow-sm:  0 1px 3px rgba(0,0,0,0.06);
  --shadow-md:  0 4px 12px rgba(0,0,0,0.08);
  --shadow-lg:  0 12px 24px rgba(0,0,0,0.1);
  --shadow-xl:  0 20px 40px rgba(0,0,0,0.12);
}
```

### 2.3 当前状态（2026-04-26）

**状态：已完成（100%）**

- `src/styles/global.css` 已补齐 `--bg-app`、`--bg-surface`、`--bg-elevated`、`--text-primary`、`--border-default`、`--accent` 等语义 token。
- 旧体系 `--bg-page` / `--bg-panel` / `--primary` 与现有 `--color-*` 已改为映射到同一语义层，双轨漂移明显收敛。
- `light / dark / soft` 三套主题都已同步到新语义变量，并补了 workspace 变量在深色 / 柔和主题下的映射。
- 历史页面中的静态硬编码色值已完成替换；当前保留的是图表、图谱、进度条和调色板等运行时数据驱动色值。
