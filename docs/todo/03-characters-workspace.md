# 人物工作区重构

## 问题
- 人物页原来把人物列表、关系图、长表单主要堆在两列里，编辑时容易上下找内容。
- 列表切换人物后，关系和档案上下文不够稳定。
- AI 入口分散在页面头部和表单顶部，语义不统一。

## 原因
- 旧布局是“左侧列表 + 右侧上下堆叠图谱和表单”。
- 长表单天然会把整个编辑区拉长。
- 关系图和当前档案不在同一视野层级。

## 解决措施
- 调整为三栏稳定结构：人物列表、关系图谱、人物档案。
- 人物列表和人物档案改为独立滚动并吸附，减少整页滚动依赖。
- 统一 AI 按钮文案为“生成 / 补全 / 修复”语义。
- 保留关系摘要和关联物品在档案区底部，形成当前人物闭环。

## 状态
- 状态：已解决
