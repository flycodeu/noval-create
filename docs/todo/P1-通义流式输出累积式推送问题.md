# P1 - 通义千问流式输出是累积式推送

> 优先级：P1（严重问题）
> 影响范围：阿里通义模型的流式输出正确性
> 实现难度：低

---

## 问题

通义千问的 SSE 流式响应是**累积式**（每次返回完整已生成内容），而非增量式（每次只返回新增 delta）。当前 `AliyunAdapter.stream()` 直接将 `output.text` 或 `output.choices[0].message.content` 传给 `onStream`，导致内容重复叠加。

例如：通义返回 "你好" → "你好世界" → "你好世界。"，当前逻辑会推送 "你好" + "你好世界" + "你好世界。"，最终拼接结果为 "你好你好世界你好世界。"。

## 原因

`AliyunAdapter.stream()` 的 `consumeSseStream` 回调中没有做增量差分（delta extraction）：
```typescript
const content = parsed?.output?.choices?.[0]?.message?.content || parsed?.output?.text
if (content) {
  opts?.onStream?.(content)  // ← 直接推送全量
}
```

## 解决方式

在 `AliyunAdapter.stream()` 中维护 `previousContent`，对通义的累积式 SSE 做增量差分，只把新增文本推给 `onStream`。同时保留异常前缀变化时的兜底分支，避免丢字。

已解决

## 预期效果

- 通义千问的流式输出不再重复，章节内容正确
- 前端实时显示的流式文字是逐步增量推送
