# P1 - 流式输出无大小上限

> 优先级：P1（严重）
> 影响范围：主进程内存安全
> 实现难度：低
> 类别：后端-任务系统

---

## 问题

`runStreamTask()` 中的 `fullOutput += chunk` 无限制地累积字符串。正常情况下 AI 回复几千字不会有问题，但如果模型异常（如无限循环输出、API 返回格式错误导致无法正常结束），会持续累积直到耗尽主进程内存。

```typescript
onStream: (chunk) => {
  fullOutput += chunk  // 无大小限制
  if (opts.sender && !opts.sender.isDestroyed()) {
    opts.sender.send('task:stream-chunk', { taskId, chunk })
  }
},
```

## 原因

- `electron/services/task.service.ts:740` fullOutput 字符串拼接无上限检查
- 没有安全阀机制来中止异常长的输出

## 解决方式

1. 添加 `MAX_STREAM_OUTPUT_LENGTH` 常量（如 524288，约 512K 字符）
2. 在 `onStream` 回调中检查 `fullOutput.length`，超过上限时设置标志位并调用 `controller.abort()` 中止流
3. 在 catch 块中检测该标志位，记录为 `failed` 状态并提供明确的错误信息

## 是否解决

已解决

## 预期效果

- 异常长输出会被安全截断并标记任务失败
- 主进程内存不会因单个异常任务而耗尽
- 用户会收到明确的错误提示
