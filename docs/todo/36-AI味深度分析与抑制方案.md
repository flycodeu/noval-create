# 36 - AI 味深度分析与抑制方案

## 一、当前反 AI 味体系的优势

系统已有的反 AI 味设计在国内同类产品中属于**顶级水准**，具体体现在：

### 1.1 提示词层面（prompt-library.ts）

- **748 行全局写作规则**，包含 "坏→好" 对照示例
- **禁用词黑名单** + 强制替代方案
- **角色差异化声音锁**：口头禅、用词水平、句式偏好
- **题材特化约束**：每个题材有独立的真实性规则
- **对白真实性**：允许打断、省略、不回答、沉默

### 1.2 质量检测层面

- `anti-ai-rule.service.ts`：硬约束生成
- `dialogue-fingerprint.service.ts`：角色声音指纹
- `style-analysis.service.ts`：作者风格指纹
- `narrative-control.service.ts`：叙事控制分析
- `workspace-quality.service.ts`：整体 AI 味评分

### 1.3 生成流程层面

- Draft → Review → Rewrite 三阶段修正
- 审校报告包含 `human_language_repairs`、`genre_hollowing_risks`
- 合同验收门控保证结构承诺兑现

## 二、仍然可能泄露 AI 味的六个维度

### 2.1 跨章节表达复用（高风险）

**问题**：单章反 AI 效果很好，但写到 30+ 章后，AI 容易在**不同章节的相似情境**中使用近似的表达结构。

**典型表现**：
- 每次角色受伤时都用"疼痛让他清醒了几分"
- 每次紧张场景都用"指节因用力而发白"
- 每次高潮前都用"空气似乎凝固了"——虽然不在黑名单里，但频繁出现就暴露了

**建议方案**：
1. 新增 `expression-dedup.service.ts`，对最近 N 章做短语级 n-gram 分析
2. 当 3-gram/4-gram 重复率超过阈值时，在下一章的 hard constraint 中注入"本章禁止使用以下表达：..."
3. 在质量仪表盘增加"表达多样性"指标

### 2.2 情感高潮结构雷同（中高风险）

**问题**：AI 在写"高燃""虐心""转折"等高情感密度段落时，容易使用相似的**修辞升级模式**。

**典型模式**：
```
长句描写铺垫 → 句子逐渐变短 → 碎片化/独句成段 → 关键句反复 → 一句话收束
```

即使内容不同，这种**结构指纹**在多个高潮章节中反复出现时，读者会感知到"机械感"。

**建议方案**：
1. 在 Scene Plan 阶段注入**结构变体指令**：本章高潮请使用方式 X（从预设的 6-8 种高潮写法中轮换选择）
2. 变体库示例：
   - 模式 A：长句蓄力 → 突然中断 → 留白
   - 模式 B：对话推进 → 动作爆发 → 无内心描写
   - 模式 C：感官细节堆叠 → 时间变慢 → 声音消失
   - 模式 D：旁观者视角切入 → 碎片信息 → 事后回忆补全
   - 模式 E：平静叙述 → 突然一句揭露 → 不做任何渲染

### 2.3 过渡段的信息密度均匀化（中等风险）

**问题**：AI 写过渡段时倾向于**均匀分配信息密度**——每段大致等长，每段都有一个小信息点。人类作者会有明显的**疏密节奏**。

**建议方案**：
1. 在章节合同中增加"过渡节奏指令"：本章过渡段要求 2-3 段密集 + 1 段极简（只有一个动作）
2. 审校阶段检查段落长度方差——方差过小则标记为"节奏平庸"

### 2.4 角色内心戏的平衡术（中等风险）

**问题**：AI 写角色内心戏时倾向于**两面兼顾**——既表达决心也表达犹豫，既显示强硬也暗示脆弱。这种"面面俱到"的心理描写反而暴露了 AI 的"不愿得罪"倾向。

**建议方案**：
1. 每章指定角色的**情绪主基调**，禁止在同一段落内出现超过 2 个对立情绪
2. 允许"单色情绪章节"——某些章节角色就是纯粹愤怒/纯粹绝望，不需要平衡
3. 在角色弧线设定中增加"当前情绪阈值"——该角色目前到了什么阶段，能感受多少层情绪

### 2.5 世界观说明的教科书语气（中等风险）

**问题**：当需要介绍世界观设定（修炼体系、科技体系、势力关系）时，AI 容易滑入"说明文"语气——用第三人称客观视角解释规则，而非通过角色体验或对话自然展示。

**建议方案**：
1. 在世界观相关章节的合同中强制"信息传递方式"：只通过角色互动/经历展示，禁止解释性段落
2. 审校阶段检测"连续 3 句以上无角色行动的纯叙述"并标记

### 2.6 章首章尾的模式化（低中风险）

**问题**：AI 章首倾向于用环境描写开头，章尾倾向于用悬念/反思收尾。长篇累积后，每章的"开头+结尾"形成可预测的框架。

**建议方案**：
1. 在章节合同中加入"开头方式"和"结尾方式"字段，从多种预设中选择
2. 开头预设：对话直入、动作开场、物件特写、时间跳跃、回忆闪入
3. 结尾预设：中断式（句子没说完）、行动式（角色转身走了）、第三人入场、环境归于平静、画面定格

## 三、执行优先级

| 优先级 | 维度 | 实施复杂度 | 效果预期 |
|--------|------|------------|----------|
| P0 | 跨章节表达去重 | 中 | 显著降低长篇 AI 味 |
| P0 | 情感高潮结构变体 | 低 | 直接提升高潮章节质量 |
| P1 | 过渡段疏密控制 | 低 | 改善整体阅读节奏 |
| P1 | 角色内心戏单色化 | 低 | 增加角色真实感 |
| P2 | 世界观融入式展示 | 中 | 减少"说明文"感 |
| P2 | 章首章尾多样化 | 低 | 打破结构可预测性 |

## 四、长期建议

1. **建立 AI 味评分体系 2.0**：当前 aiCheck 是单章评分。需要增加**全书级 AI 味评分**，检测跨 20+ 章的模式重复、结构雷同和表达同质化。
2. **人类作者对照库**：收集目标题材优秀作品的表达模式统计（段落长度分布、句式变化频率、情感密度曲线），作为生成质量的参照基准。
3. **渐进式约束释放**：前 10 章使用严格 AI 味约束，中期（11-50 章）逐步释放部分约束让 AI 发挥更多创造性，后期（50+ 章）重新收紧但重点转向"跨章节去重"。
