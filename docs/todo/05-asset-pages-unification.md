# 非正文资产页统一布局

## 问题
- 势力、物品、词典、时间线、结构等页面仍可能延续“筛选 + 列表 + 长表单”整页滚动模式。
- 各资产页布局风格不一致，用户切页后的操作预期不稳定。

## 原因
- 之前每个页面各自实现，没有共享的资产页布局规则。
- 页面很多，但高频问题主要集中在共享容器层，没有先做抽象。

## 解决措施
- 以共享工作区和可滚动面板为基础，把更多资产页逐步收口到统一模式。
- 优先套用“列表 / 主视图 / 详情”或“主视图 / 侧栏检查器”两类模板。
- 后续逐页检查高频资产页，把仍然依赖整页滚动的页面改成分区滚动。

## 状态
- 状态：处理中
- 说明：共享基础能力已具备，但其余资产页还需要逐页套入新模式。
