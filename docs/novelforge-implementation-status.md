# NovelForge 长篇能力实施状态

更新时间：2026-08-09

状态含义：

- `已完成`：代码、测试和必要的运行证据均具备；
- `进行中`：已有代码基础，但仍缺关键闭环或验证；
- `待实现`：设计已确定，尚未进入代码；
- `待真实验证`：静态检查通过，但需要真实模型、数据库或长篇运行证据。

## 本轮实施顺序

1. 设计文档和数据契约；
2. 正典事件/状态提交层；
3. 节点 artifact、租约和精确重试；
4. 增量上下文与混合检索；
5. Worker、outbox、人物知识和地图旅行约束；
6. UI Diff、智能侧栏、时间轴和深色专注模式；
7. 运行 20/50/100/300 章验证并逐项更新本表。
