# 2.4.34 界面与操作流程检查

## 范围与边界

以 `src/App.tsx`、`src/pages/Novel/index.tsx` 的实际路由和导入关系为准，检查当前六个创作工作区、六个全局页面及其设置、编辑、候选、查找和退出弹窗。旧页面源码大多已无活动入口；旧链接仍须兼容，但不把孤立旧组件测试当作当前界面验证。

不修改正式作品数据库，不自动应用候选，不调用用户的模型、搜索或朱雀密钥，不安装或重启正式桌面应用。

## 共享界面与架构

- 小说标题栏补回后台任务入口，通过工作区导航回调执行离开保护，避免打开任务记录时丢失未保存内容。
- 任务取消增加提交锁与进行中状态，失败后保留任务并允许重试；弹层使用视口宽高约束。
- 全局导航统一页面名称，直达高级工具时展开当前项，窄屏显示当前工具；主题按钮增加可读状态，侧栏菜单有界滚动。
- 跨作品关闭查找弹窗并清理关键词、结果和错误，迟到请求不能显示另一部作品的内容。
- 联网搜索设置拆成独立组件，模型目录选择为独立控件；后端统一发现模型并校验已保存密钥的提供商和完整 Base URL，不向新地址或重定向发送旧密钥。
- 模型保存后的列表刷新也属于提交过程；期间锁定新建、切换与编辑，避免旧配置覆盖随后打开的新建表单。
- 删除重复的正常退出介绍和空泛错误说明。未保存、删除不可恢复、退出停止任务、密钥、候选应用、过期结果与失败提示保留，不用全局 CSS 隐藏说明。
- 历史规划/基础设定草稿改为在运行记录中只读查看，不将 `recoverDraft` 参数发送到没有接收逻辑的新工作区，也不擅自写回。

## 验证方式

`test:global-ui` 和 `test:workspace-layout` 使用真实 App、HashRouter 和生产 React 组件，在隔离 Electron profile 中运行；服务为显式受控响应。全局测试检查根节点和主要容器的内部溢出，不以隐藏滚动条代替布局修复。模型配置测试和真实本地 Web RPC 测试覆盖发现模型、保存密钥复用、地址变更拒绝和搜索测试不持久化。

本文件只记录工程检查和修复，不表示所有历史页面或所有数据组合都经过人工验收，也不表示真实供应商已联通。发布以对应标签的 GitHub Actions 最终成功状态及资产校验为准。
