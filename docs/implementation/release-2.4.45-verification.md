# 2.4.45 验证记录

日期：2026-10-24。

本版保留现有工作区修改，发布人物与创作资料布局、图谱增量更新和审校对照改进。本轮代码验证未修改正式小说数据库、章节标题、正文或剧情规划。

## 修复与复核

- 图谱嵌套规划递归合并，同章局部更正保留原章初/章末时序，新章变更默认章末。回归覆盖规划字段保留、明确改时序与反向回写冲突。
- 人物作用作为作者规划保存，旧分类保留兼容映射；人物图按实际关系分组，允许独立人物和配角关系群。图中节点可拖动，右侧面板可调宽，支持键盘和窄屏布局。
- 创作资料改为可展开的条目，理解和本作用途可选；省略可选字段保留旧值，显式空字符串清空。补齐个人资料编辑中残留的强制理解字段。
- 审校对照展示结论、正文版本、逐项要求及分类问题；旧报告、未保存草稿禁用定位修订。章节切换丢弃过期请求结果。
- 快速创建测试使用已有关键词回退；RF-11 使用本机模拟向量接口，发布检查使用关键词回退，避免隐式下载本地模型。真实离线向量推理仍由独立测试验证。
- 官方 npm 全量审计发现两项高风险依赖，锁文件更新 body-parser 2.3.0 → 2.4.0、zod 3.25.76 → 4.6.7，以及 body-parser 所需 content-type、qs。沿现有依赖声明解析，未增加强制覆盖或放宽审计规则。
