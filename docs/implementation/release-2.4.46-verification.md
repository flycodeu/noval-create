## 修复与复核

- 作品书架与作品标题区展示封面、书名及作品信息。封面复用已有存储字段，支持上传、生成候选、明确采用与清除，不做数据库迁移。保存比较原封面，冲突不覆盖；前端只合并封面元数据，不以旧响应覆盖作品内容。
- 图片生成复用已配置的 OpenAI / 自定义连接，单独指定图片模型。请求不自动重试收费操作；拒绝重定向、URL-only 响应、SVG、过大响应及无效图片，错误不暴露凭据和供应商原文。未验证任意真实供应商兼容性。
- 页面错误边界显示中文恢复入口，不直接展示内部异常、源码路径和模块地址。动态模块加载失败使用页面重载，普通渲染错误允许重试；保留控制台诊断。
- 正文保存完成后，继续操作前复核加载代次、当前章节和实际保存快照。切章或出现更新的草稿时，不继续旧审校、修订或导航；旧保存错误不落到新章节。版本恢复在确认和写入后复核目标有效性。
- 资料提炼的预算预览与生成绑定到当前窗口会话，关闭、重开、切书和卸载均使旧预览失效，避免延迟响应启动隐藏的生成任务。复用 scoped state 恢复新会话的忙碌状态；同会话重复提交有即时互斥。
- 回归在修复前分别复现保存后审校边界、关闭后仍启动提炼的问题，修复后通过，并接入原有默认 Hooks 浏览器测试链。
- 复核资料编辑、文风、候选、选区修订与顶部栏的既有组件拆分，保留字段合并、冲突检查、历史和未保存草稿保护。
