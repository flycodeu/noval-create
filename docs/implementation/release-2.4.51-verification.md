# NovelForge 2.4.51 验证记录

## 修复结果

已写上章与目标章明确登记为同一个唯一视角人物时，普通动作和对白段落可以作为续写依据，无须逐字重复事实卡标题或摘要。来源章节的每个场景段落均须有视角登记，孤立合同不能替未登记段落作证。明确隐藏事实仍优先整段脱敏，未解析视角、跨视角未知资料、同章和未来正文继续受隔离检查。

正文生成与旧章检索采用同一原文投影规则，移除创作路径与召回路径各自恢复未分类段落的绕过处理。预算选择不会重新纳入原先已隔离的来源。

必需资料被隔离时返回独立的 `NF_CONTEXT_VISIBILITY_BLOCKED`，不再报告为零缺口的预算溢出；生成管线保持阻断，界面提示核对视角、知情记录与揭示时点。

本次从 `e2f65f5` 的隔离工作区构建，包含上下文修复、回归测试、依赖安全更新与版本资料。主工作区其他未提交改动保持原样。
