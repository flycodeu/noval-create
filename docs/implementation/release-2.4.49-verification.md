# NovelForge 2.4.49 验证记录

日期：2026-10-27。范围：管理页面精简、运行历史清理与结构化数据展示。

## 变更范围

- 审核六个全局管理页面及七个写作工作区；主要调整模型与搜索、应用设置、运行记录、提示词与模板管理，不重做正文、人物图谱或审校工作流。
- 模型身份、预算和操作分层；辅助服务宽屏并排；管理详情按需展开。保留模型发现、配置测试、凭据隔离及未保存修改保护。
- 设置页收紧标题和间距，诊断按需展开；提示词筛选收为两个下拉框，去重复标签；模板统计归并至目录栏。长参数标签允许换行，不裁掉字段。
- 运行记录支持单条删除、筛选删除、只读预览和可选自动清理。自动清理默认关闭、保留期限默认 30 天，应用运行期间每小时检查。
- 仅删除已结束且到期的任务；活跃任务、草稿、成果引用、审校来源、快照、恢复节点和相关父子/上游链保留。任务删除事务化，日志只处理白名单内的过期文件，不碰小说、资料或其他文件。
- JSON 支持结构树与格式化源码，常见凭据字段遮蔽，分批展开；超过预览上限不显示原始内容，原记录保留。
- 保留已有时间轴空章位修复；测试临时目录改用唯一目录，避免 Windows 文件占用影响重复运行。
